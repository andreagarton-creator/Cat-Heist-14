# The Purrfect Heist v14 Multiplayer Test
Real online room creation and joining for up to 10 players, shared lobby and scenes, synchronized player colours/positions and shared objective state.

## Test
1. Deploy this complete repository to Railway.
2. Player 1 enters a name and clicks Create Game.
3. Share the four-digit room code shown in the Lobby.
4. Player 2 opens the same Railway URL in another browser/device, enters a name and the code, then clicks Join Game.
5. Both choose different available Cat colours.
6. The host starts and controls scene progression. All players control their own Cats.

For today's test keep Railway on one replica because rooms are stored in server memory.
